# 摘要

TCC-SOCS 空中像计算是 OPC/SMO 中的关键环节，其在线重构包含大量二维 IFFT 与逐像素累加。本文的主要创新是提出并实现一种 FPGA/HLS 软硬件协同框架：由 CPU 离线完成 TCC 构建、特征分解与 SOCS 核提取，由 FPGA 在线完成频域嵌入、128×128 二维 IFFT、强度累加及结果输出。通过 HLS FFT IP、块浮点缩放、`use_luts` 映射、多 AXI-MM 接口和 BRAM 缓冲，DSP 用量由 8,064 个降至 34 个。xcku5p 板级验证表明，10 核计算 RMSE 为 $2.93\times10^{-8}$，延迟约 10.57 ms，能效较 CPU 提升约 67.4 倍，为低延迟、高能效空中像评估提供了可部署方案。

**关键词**：计算光刻；TCC-SOCS；空中像计算；FPGA；HLS；软硬件协同。
