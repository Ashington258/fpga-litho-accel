## 3. 主图像的具体准备要求

### A1 输入掩模

现有来源：

- [../../../../output/verification/mask.png](../../../../output/verification/mask.png)
- [../../../image/论文/ch5_fig7_mask_patterns.png](../../../image/论文/ch5_fig7_mask_patterns.png)

建议使用单个默认测试图形，不要在主流程中使用 10 个 ICCAD 图形拼图。

处理要求：

- 保留二值黑白效果。
- 去除坐标轴、标题和白边。
- 与最终空中像保持相同空间方向。
- CPU 和 FPGA 流程复用同一个图像文件。

### B1 掩模频谱

数据来源：

- `output/verification/mskf_r.bin`
- `output/verification/mskf_i.bin`
- `data/pc_cpp/output_10kernels/mskf_r.bin`
- `data/pc_cpp/output_10kernels/mskf_i.bin`

计算方式：

$$
|\hat M|=\sqrt{\hat M_{\mathrm{Re}}^2+\hat M_{\mathrm{Im}}^2}.
$$

显示方式：

$$
V=\log(1+|\hat M|).
$$

建议准备两个版本：

- `b_mask_spectrum_full.png`：完整 1024×1024 频谱，用于方法介绍。
- `b_mask_spectrum.png`：适合流程图的正方形缩略图，可强化显示中心频率区域。

### B2 SOCS 本征核拼图

现有候选：

- [../../../image/论文/socs_kernel_concat.png](../../../image/论文/socs_kernel_concat.png)
- [../../../image/论文/Dominant%20Kernels.png](../../../image/论文/Dominant%20Kernels.png)
- [../../../image/论文/ch3_fig7_dominant_kernels.png](../../../image/论文/ch3_fig7_dominant_kernels.png)

原始数据来源：

```text
data/pc_cpp/output_10kernels/kernels/krn_k_r.bin
data/pc_cpp/output_10kernels/kernels/krn_k_i.bin
```

建议显示每个核的幅值：

$$
|\Phi_k|=\sqrt{\Phi_{k,\mathrm{Re}}^2+\Phi_{k,\mathrm{Im}}^2}.
$$

准备要求：

- 使用 `2×5` 排列展示前 10 个核。
- 每个核下方只标 `k=1` 至 `k=10`。
- 所有核共享同一归一化规则。
- 流程图缩略版可只显示前 3 个核，并用省略号表示其余核。

### B3 特征值权重图

建议文件：`b_eigenvalue_weights.png`。

数据来源：

- `output/verification/scales.bin`
- `data/pc_cpp/output_10kernels/scales.bin`
- `data/pc_cpp/output_10kernels/kernels/kernel_info.txt`

建议使用 10 根简洁柱状条表示 $\sigma_1$ 至 $\sigma_{10}$，不显示坐标网格。它可与 SOCS 核拼图组成 `(b)` 节点，表达“核 + 权重”的离线数据包。

### C1 单核频域乘积

建议准备三张基础图：

| 文件名 | 内容 |
| --- | --- |
| `c_mask_window.png` | 从掩模频谱中心提取的 17×17 有效窗口 |
| `c_kernel_single.png` | 第一个或主导 SOCS 本征核的 17×17 幅值 |
| `c_frequency_product.png` | 逐点复乘 $\hat M\Phi_k$ 的幅值 |

主图可组合显示：

```text
Mask spectrum window × SOCS kernel = frequency-domain product
```

选择第一个主导核 `k=1`，并在 CPU 和 FPGA 两条流程中使用相同数据。

### C2 固定 128×128 FFT 网格嵌入

建议文件：`c_embedded_grid_128.png`。

图像必须表达：

- 全图为 128×128 网格；
- 仅 17×17 区域包含有效频域乘积；
- 其余区域为零；
- 使用矩形边框标出有效区域；
- 图下注明 `17×17 valid support in a fixed 128×128 grid`。

坐标尚未最终统一前，不在图中写 `centered`。需要先核对 CPU Golden、HLS C/RTL 与论文公式使用的嵌入位置。

### C3 单核二维 IFFT 相干场

建议文件：`c_ifft_field_magnitude.png`。

建议显示：

$$
E_k(x,y)=\mathcal{F}^{-1}\{\hat M\Phi_k\},
\qquad |E_k(x,y)|.
$$

辅助版本可准备：

- `c_ifft_field_real.png`；
- `c_ifft_field_imag.png`；
- `c_ifft_field_magnitude.png`。

主流程只使用幅值图，避免复数实部和虚部增加阅读负担。

### D1 单核强度

建议文件：`d_single_kernel_intensity.png`。

显示内容：

$$
I_k(x,y)=\sigma_k|E_k(x,y)|^2.
$$

与 `c_ifft_field_magnitude.png` 使用相同空间方向，但强度图采用统一的线性强度范围。

### D2 多核部分累加

建议文件：

- `d_partial_sum_k01.png`；
- `d_partial_sum_k05.png`；
- `d_partial_sum_k10.png`。

计算内容：

$$
I^{(K)}(x,y)=\sum_{k=1}^{K}\sigma_k|E_k(x,y)|^2.
$$

用途：

- 主流程只使用 `k=10`。
- `k=1/5/10` 可组成辅助图，解释多核累加和 SOCS 低秩收敛。
- CPU 和 FPGA `(d)` 使用相同视觉内容，差别通过节点边框和执行标签表达。

### D3 FPGA 128×128 输出

建议文件：`d_fpga_output_128.png`。

数据来源候选：

- FPGA 板上回读的 128×128 BIN；
- `tmpImgp_full_128.bin` 软件参考；
- Host 全平台输出目录中的 FPGA 中间结果。

该图必须使用真实 FPGA 回读结果。如果暂时使用 CPU Golden 代替，应在文件名和图注中标为 `reference`，不能标为 FPGA output。

## 7. 图像生成统一规范

### 7.1 数值处理

- 频谱和核幅值：使用 $\log(1+|X|)$ 或在图注明确幅值归一化。
- 空中像与强度：使用线性数值，不使用对数显示。
- 误差图：显示绝对误差 $|I_{\mathrm{FPGA}}-I_{\mathrm{CPU}}|$。
- 禁止对 CPU 与 FPGA 输出分别执行独立最大值归一化。
- 保存绘图所用 `vmin`、`vmax`，保证所有输出可复现。

### 7.2 视觉处理

- 所有步骤图输出为正方形。
- 建议单图至少 `800×800 px`，最终流程缩略图再统一缩放。
- 背景使用白色或透明，不添加阴影。
- 去除坐标轴、刻度、标题和 colorbar。
- 有效频域区域使用细边框标出，不遮挡图像内容。
- 图像方向统一，不在不同节点单独旋转或翻转。

### 7.3 文件格式

- 中间素材保存为无损 PNG。
- 最终流程图保存为 `.drawio` 源文件。
- 论文插图导出 PDF 或 SVG。
- Markdown 预览额外导出 300 dpi PNG。

## 9. 最终验收清单

- [ ] 输入掩模在 CPU 与 FPGA 流程中完全一致。
- [ ] 掩模频谱由实部和虚部共同计算幅值。
- [ ] SOCS 核图与当前 10 核配置匹配。
- [ ] 频域乘积使用同一掩模窗口和同一个主导核。
- [ ] 128×128 图明确标出 17×17 有效区域。
- [ ] 嵌入位置与 CPU Golden 和 HLS 实现一致。
- [ ] IFFT 相干场和强度平方没有混淆。
- [ ] 10 核部分和使用 $\sigma_k$ 加权。
- [ ] FPGA 128×128 图来自真实硬件回读或明确标为参考。
- [ ] CPU 与 FPGA 最终空中像使用相同色标和裁剪范围。
- [ ] 误差图比较的是相同 10 核 SOCS 配置。
- [ ] 完整 TCC 对比被标为 SOCS 截断误差，不标为 FPGA 数值误差。
