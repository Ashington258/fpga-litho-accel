## 审稿时的使用原则

1. I01 与 I06 使用相同输入图，证明两条流程没有改变输入条件。
2. I03 与 I08 使用相同强度图，证明 CPU 和 FPGA 实现的是相同 SOCS 数学算子。
3. I05 与 I10 使用相同色图和强度范围，便于直接比较最终成像结构。
4. I09 和 I10 是真实 FPGA 数据；不得将架构示意图 I02、I03、I07、I08 描述为板上测量结果。
5. I04 仅用于 CPU 行的 128×128 结构对齐。当前仓库未保留独立 CPU `tmpImgp_full_128.bin`，因此图内标注为 `CPU reference shape`；最终投稿前可重新运行 Golden 程序替换。
6. 流程主图不放 colorbar。图片说明中统一写明频谱使用对数幅值，空中像使用线性强度。

## 当前可直接用于论文的真实结果

- I05：CPU 10 核 SOCS 最终空中像。
- I09：FPGA 10 核 128×128 板上输出。
- I10：FPGA 板上输出经 Host FI 后的最终空中像。

I09 已在全平台报告中与 Golden 结果比较，RMSE 为 $2.93\times10^{-8}$；I10 与 CPU 10 核 SOCS 参考结果比较，RMSE 为 $2.95\times10^{-8}$。
